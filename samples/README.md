# Sound libraries

Put your own WAVs here; they show up in the **Sounds** tab under "MLabs samples".

To add the free VCSL drums and percussion (CC0, about 1.5 GB), run from the project folder:

```
python get_sounds.py
```

Any other folder of WAVs you own can be added from the Sounds tab with "+ Add folder…". Folders are read in place, never copied.
